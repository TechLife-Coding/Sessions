Password Validator

A simple Python program that checks whether a password follows a specific format.

📌 Project Description

This project asks the user to enter a password and validates it based on these rules:

- The password must contain exactly 8 characters.
- The first 4 characters must be letters.
- The last 4 characters must be numbers.
- If the password follows the required format, the program displays "Password is Valid".
- Otherwise, it displays "Password is Not Valid" and shows the required format.

🛠️ Technologies Used

- Python

▶️ How to Run

1. Make sure Python is installed.
2. Run the "UserPass.py" file.
3. Enter a password when prompted.
4. The program will check whether the password is valid.

💡 Example

Valid Password

pass : abcd1234

Password is Valid

Invalid Password

pass : abc12345

Password is Not Valid

The Password Should be Only 8 Characters
First 4 Characters (Letters) Second 4 Characters (Numbers)
