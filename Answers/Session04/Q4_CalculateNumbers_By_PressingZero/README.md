Calculate Numbers by Pressing Zero

A simple Python program that takes numbers from the user and calculates their total sum.
The program stops when the user enters 0 and then prints the final sum.

How It Works

- The program starts with a sum of "0".
- It repeatedly asks the user to enter a number.
- Each number is added to the total sum.
- When the user enters "0", the program:
  - Prints the total sum.
  - Stops the loop using "break".

Example

enter number: 10
enter number: 20
enter number: 15
enter number: 0
45.0
