# 🧮 Python Calculator

A simple command-line calculator written in Python.

This project supports several mathematical operations and allows the user to perform calculations repeatedly.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Floor Division
- % Modulo
- √ Square Root
- ABS Absolute Value
- ABS & SQRT Absolute Value + Square Root
- 🔁 Runs continuously using a loop

## 🛠️ Technologies

- Python 3
- math module
- subprocess module

## 🚀 How to Run

Make sure Python is installed on your computer.

Run the program using:

`bash
python Calculator.py
📌 How to Use
Enter the first number.
Choose an operation.
Enter the second number.
The calculator displays the result.
The program can continue performing calculations.
