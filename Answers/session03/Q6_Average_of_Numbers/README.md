# Average Numbers

A simple Python program that receives 10 numbers from the user and calculates their average.

## How It Works

The program uses a for loop to receive 10 numbers.

- The user enters a number 10 times.
- Each number is added to the total sum.
- After all 10 numbers are entered, the total is divided by 10.
- The final result is the average of the entered numbers.
