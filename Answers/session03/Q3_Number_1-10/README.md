# Number 1-10

## 📌 Project Description

This is a simple Python project that takes 10 numbers from the user and performs different operations depending on whether each number is even or odd.

- If the number is even, it is multiplied by 5 and added to the even-number total.
- If the number is odd, 5 is added to it and the result is added to the odd-number total.
- At the end, both totals are added together and the final result is displayed.

---

## 🧠 How It Works

The program uses a for loop to receive exactly 10 numbers from the user.

### Even Numbers

For an even number, the program uses:

`python
value1 += number * 5
For example:
2 × 5 = 10
Odd Numbers
For an odd number, the program uses:
value2 += number + 5
For example:
3 + 5 = 8
At the end, the two values are added together:
sum1 = value1 + value2
The final result is then printed to the console.
