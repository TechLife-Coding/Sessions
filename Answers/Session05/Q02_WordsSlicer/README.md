# Remove Duplicate Characters

A simple Python program that takes a string as input and removes all duplicate characters, keeping only the first occurrence of each character.

## How It Works

The program checks each character in the input string.

- If the character has not appeared before, it is added to the result.
- If the character already exists in the result, it is skipped.

## Example

### Input

`text
banana

Output
ban
