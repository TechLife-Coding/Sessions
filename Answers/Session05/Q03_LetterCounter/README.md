Character Counter

A simple Python program that receives a string from the user and counts different types of characters in it.

## Features

The program counts:

- English letters
- Uppercase letters
- Lowercase letters
- Digits
- Spaces
- Special characters

## Example

### Input

`text
Python 123! ABC
Output
Letters: 9
Uppercase: 4
Lowercase: 5
Digits: 3
Spaces: 2
Special characters: 1
