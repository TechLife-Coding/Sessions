# Find Specific Words

## Description

Write a Python program that receives a text from the user and searches for the following words:

- hack
- fraud
- scam
- password
- attack

The program should display each word that exists in the text and the number of times it appears.

## Example

### Input
text
This is a password attack and another password attack

Output
password -> 2
attack -> 2
