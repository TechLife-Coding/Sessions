# Login System

## Description

Write a Python program that implements a simple login system.

The user must enter a username and password.

The user has a maximum of 3 attempts to log in.

If the username or password is incorrect, the program should display an error message and show the number of remaining attempts.

If the information is correct, the program should display a successful login message.

Wrong user name or password.
Attempts remaining: 2
