# Password Validator 🔐

A simple Python program that checks whether a password meets basic security requirements.

## Features

The program checks if the password:

- Has at least 8 characters
- Contains an uppercase letter
- Contains a lowercase letter
- Contains at least one number
- Contains at least one special character such as @, !, $, #, &, %

If the password does not meet the requirements, the program displays the reasons why it is invalid.
