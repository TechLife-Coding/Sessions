# String Counter

A simple Python program that receives a string from the user and checks its length.

## 📌 Description

This program takes a string as input and checks whether its length is even or odd.

- If the length of the string is even, the program prints the first half of the string.
- If the length of the string is odd, the program prints the second half of the string.

## 🛠️ Technologies

- Python 3

## ▶️ How to Run

Run the Python file:

`bash
python StringCounter.py
Then enter a string when the program asks for it.
💡 Example
Input:
ABCDEFGH
Output:
ABCD
Because the length of ABCDEFGH is 8, which is even.
Another Example
Input:
ABCDEFG
Output:
DEFG
Because the length is 7, which is odd.
