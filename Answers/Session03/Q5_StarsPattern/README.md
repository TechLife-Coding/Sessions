Stars Pattern

A simple Python program that uses nested "for" loops to print a triangle pattern made of stars ("*").

How It Works

- The outer "for" loop controls the number of rows.
- The inner "for" loop controls how many stars are printed on each row.
- "end=" "" keeps the stars on the same line.
- After each row, "print()" moves to the next line.

Example Output

*
* *
* * *
* * * *
* * * * *
* * * * * *

Concepts Used

- "for" loops
- Nested loops
- "range()"
- "print()"
- "end" parameter
