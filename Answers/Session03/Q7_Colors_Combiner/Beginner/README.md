Color Similarity Checker

A simple Python program that takes three colors from the user and checks whether any of them are the same.

📌 How It Works

The program asks the user to enter three colors using a "for" loop.

Then it checks the colors using:

- "if"
- "elif"
- "else"
- "list"
- "for" loop
- "input()"
- String comparison

🔹 Possible Results

- If all three colors are the same:
  
  Three colors same

- If two colors are the same:
  
  Same

- If all three colors are different:
  
  No colors are the same

🧠 Example

Input:

Choose a color: red
Choose a color: blue
Choose a color: red

Output:

Same

🎯 Purpose

This project is designed to practice basic Python concepts such as lists, strings, loops, conditions, and user input.
