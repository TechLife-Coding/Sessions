Random Number Guessing Game

This program is a simple number guessing game written in Python.

How It Works

The program generates a random number between "1" and "100" using the "random" module.

The user has up to 19 attempts to guess the random number.

After each guess, the program gives feedback:

- If the guessed number is greater than the random number, it tells the user that their guess is too high.
- If the guessed number is smaller than the random number, it tells the user that their guess is too low.
- If the guessed number is equal to the random number, it displays a congratulation message and stops the loop using "break".

Concepts Used

- "import random"
- "random.randint()"
- "for" loop
- "range()"
- "input()"
- Type conversion using "float()"
- "if / elif" statements
- Comparison operators
- "break"

Purpose

The purpose of this exercise is to practice random numbers, loops, conditional statements, user input, and comparison operators in Python.
